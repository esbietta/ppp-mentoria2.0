
# Plano de Testes

## Objetivo
Garantir a qualidade da API PPP Mentoria 2.0 através da validação dos principais fluxos funcionais.

## Escopo
- autenticação
- transferências
- validações HTTP
- regras de negócio

## Fora do Escopo
- testes mobile
- UI
- acessibilidade

## Ferramentas
- Mocha
- Chai
- Supertest

## Critérios de Entrada
- API disponível
- ambiente configurado

## Critérios de Saída
- testes críticos aprovados
- ausência de bugs bloqueantes
