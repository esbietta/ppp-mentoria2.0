# PPP Mentoria 2.0 - QA Automation Project - Hotel Reservations

## Objetivo

Projeto desenvolvido para validação automatizada de APIs REST utilizando práticas de Quality Assurance.

O foco do projeto é validar:
- autenticação
- regras de negócio
- transferências
- segurança básica
- respostas HTTP
---

## Tipos de Testes Aplicados

- API Testing
- Functional Testing
- Smoke Testing
- Regression Testing
- Negative Testing
- Authentication Testing

---

## Stack Utilizada

- Node.js
- Mocha
- Chai
- Supertest
- Mochawesome
- dotenv
